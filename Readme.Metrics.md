# Metric Annualization Conventions

This repository uses two deliberately separate annualization conventions:

- **Reader-facing results:** 252 trading days per year for arithmetic returns and
  volatility-scaled statistics. Geometric CAGR uses actual elapsed calendar time.
- **Native VectorBT / legacy results:** `vbt.settings.returns["year_freq"]`
  evaluates to `"365 days"`. With portfolio `freq="D"`, VectorBT's
  annualization factor is `365.0` observations per year.

Do not combine fields from these conventions in one result row. Changing 252 to
365 multiplies an annualized arithmetic mean by `365 / 252 = 1.4484` and a
volatility-scaled statistic by `sqrt(365 / 252) = 1.2035`.

## Current Trio Tear Sheet

The following table documents every row generated by
[`notebooks/18_3_trio_10y.ipynb`](notebooks/18_3_trio_10y.ipynb). Here, `r` is the
daily portfolio return, `r_cash` is the aligned daily BIL cash return, and `r_m`
is the aligned daily SPY return.

| Tear-sheet metric | Time basis | Computation or interpretation |
|---|---:|---|
| Window | None | First and last dates of the validated performance window. |
| Trading days | Daily count | Number of aligned return observations used by every statistic in the column. |
| Total return (cum.) | None | `ending_value / starting_value - 1`. |
| CAGR (geom., ann.) | Elapsed calendar time | `(ending_value / starting_value) ** (1 / years) - 1`, where `years = elapsed_days / 365.25`. This is not a 252- or 365-row estimate. |
| Total return (ann., arith.) | 252 | `mean(r) * 252`. |
| Ann. volatility | 252 | `std(r, ddof=1) * sqrt(252)`. |
| Downside RMS (daily) | Daily, not annualized | `sqrt(mean(min(r, 0) ** 2))`. |
| Sharpe (excess BIL) | 252 | `mean(r - r_cash) / std(r - r_cash, ddof=1) * sqrt(252)`. |
| Sortino (excess BIL) | 252 | `mean(r - r_cash) / downside_RMS(r - r_cash) * sqrt(252)`. |
| Calmar | Elapsed calendar time | Elapsed-time CAGR divided by absolute maximum drawdown. |
| Max drawdown | None | Minimum of `value / running_max(value) - 1`. |
| Max DD peak | None | Date of the wealth peak preceding the maximum-drawdown trough. |
| Max DD trough | None | Date of the minimum drawdown. |
| Max DD recovered | None | First date at or above the prior peak after the trough, or an unrecovered marker. |
| VaR 95 (daily) | One trading day | Fifth percentile of daily returns. |
| CVaR 95 (daily) | One trading day | Mean of daily returns less than or equal to daily VaR 95. |
| Skew (daily) | Daily, not annualized | Sample skewness of daily returns. |
| Excess kurtosis (daily) | Daily, not annualized | Fisher excess kurtosis of daily returns. |
| Hit rate (daily > 0) | Daily, not annualized | Fraction of daily returns greater than zero. |
| SSR | 252-day rolling window | Rolling Sharpe values use `sqrt(252)` and a 252-observation window. SSR divides their mean deviation from the target Sharpe by their HAC long-run volatility. |
| SSR p (MBB) | 252-day rolling window | Moving-block-bootstrap inference on the same rolling-Sharpe path; the p-value itself is not annualized. |
| Market (beta * SPY, ann. arith.) | 252 | `beta * mean(r_m) * 252`. |
| Alpha vs SPY (ann., arith.) | 252 | Daily market-model intercept multiplied by 252. |
| Beta (SPY) | None | OLS slope from the daily raw-return regression `r ~ const + r_m`. |
| t(alpha) HAC | None | Daily-intercept t-statistic with Bartlett/Newey-West HAC standard errors and five lags. Multiplying the intercept and its standard error by the same annualization factor would not change it. |
| R2 (market) | None | R-squared from the daily SPY market-model regression. |
| Correlation (SPY) | None | Daily return correlation with SPY. With one regressor and an intercept, its square equals market-model R-squared. |
| Idio vol sigma_e (ann., CAPM) | 252 | Standard deviation of daily market-model residuals multiplied by `sqrt(252)`. |
| Appraisal ratio (alpha / sigma_e, CAPM) | 252 | 252-day annualized arithmetic alpha divided by 252-day annualized idiosyncratic volatility. |
| Active return vs SPY (ann.) | 252 | `mean(r - r_m) * 252`. |
| Tracking error vs SPY (ann.) | 252 | `std(r - r_m, ddof=1) * sqrt(252)`. |
| Information ratio (vs SPY) | 252 | Annualized active return divided by annualized tracking error, equivalent to the daily ratio multiplied by `sqrt(252)`. |
| R2 (own 4-ETF basket) | None | R-squared from the daily raw-return regression on the portfolio's four ETF factors. |
| Idio vol vs basket (ann.) | 252 | Standard deviation of daily basket-regression residuals multiplied by `sqrt(252)`. |

## Native VectorBT Metrics

Portfolio constructors in [`macro_framework/backtest.py`](macro_framework/backtest.py)
and [`macro_framework/rebalance.py`](macro_framework/rebalance.py) default to
`freq="D"`. No notebook or framework module overrides VectorBT's global
`year_freq`, so its effective annualization factor is 365.

| VectorBT metric | Time basis | Effect |
|---|---:|---|
| `total_return()` | None | Cumulative return; unaffected by `year_freq`. |
| `annualized_return()` | 365 rows | Compounds the observed return over a 365-observation year. |
| `annualized_volatility()` | 365 | Scales daily volatility by `sqrt(365)`. |
| `sharpe_ratio()` | 365 | Scales the daily Sharpe ratio by `sqrt(365)`. |
| `sortino_ratio()` | 365 | Scales the daily return/downside-risk ratio by `sqrt(365)`. |
| `calmar_ratio()` | 365 rows | Uses VectorBT's 365-row annualized return divided by maximum drawdown. |
| `max_drawdown()` | None | Path statistic; unaffected by `year_freq`. |

Because exchange data normally has about 252 rows per calendar year, the
VectorBT convention above treats 252 observed trading-day rows as only
`252 / 365 = 0.6904` years. These fields are retained for legacy parity, not as
the preferred reader-facing estimates.

## Framework Field Mapping

[`macro_framework/evaluation.py`](macro_framework/evaluation.py) emits both
families under explicit field names. [`macro_framework/reporting.py`](macro_framework/reporting.py)
keeps them in separate schemas.

| Metric family | Reader-facing field | Reader basis | Legacy field | Legacy basis |
|---|---|---:|---|---:|
| Total return | `total_return` | None | `total_return` | None |
| Geometric annual return | `cagr` | Elapsed days / 365.25 | `cagr_rows` | 365 rows |
| Annualized volatility | `ann_vol` | `sqrt(252)` | `ann_vol_cal` | `sqrt(365)` |
| Sharpe | `sharpe` | `sqrt(252)` | `sharpe_cal` | `sqrt(365)` |
| Sortino | `sortino` | `sqrt(252)` | `sortino_cal` | `sqrt(365)` |
| Calmar | `calmar` | Elapsed-time CAGR | `calmar_rows` | 365-row CAGR |
| Maximum drawdown | `maxdd` | None | `maxdd` | None |
| Downside RMS | `downside_rms` | Daily | `downside_rms` | Daily |
| Schema metadata | `periods_per_year` | 252 | `periods_per_year` | 365 |

One additional distinction matters: `evaluation.metric_block()` initially
calculates Sharpe and Sortino on raw returns. Reader report rows recompute those
two fields on the aligned portfolio-minus-BIL cash-excess stream. Legacy
`sharpe_cal` and `sortino_cal` remain raw-return, 365-basis compatibility fields.
